## Catatan adaptasi dan perbedaan hasil

1. **Versi/data:** commit `8a6d3bb6468e979c861d4b37215e1413702dfdfa` adalah snapshot repository edisi kedua yang tersedia, bukan snapshot persis cetak 2020. Dataset diverifikasi SHA-256. Parameter contoh tetap mengikuti PDF; seed dan beberapa API dimodernisasi.
2. **Bab 1:** MAD raw dibedakan dari MAD terskala; perbedaan konstanta R/Python memberi selisih kecil pada MAD. Weighted median aktual sama dengan R (4,4). `pd.cut` memperluas batas bin; hitungan cocok. Telekomunikasi pada filter tanggal buku berisi 753 baris versus 754 pada prosa. DFW ditampilkan persen dari total; grafik R dibagi enam sedangkan Python upstream tidak. Periode pada airline CSV tidak tersedia sehingga label netral, dengan 28 missing pada kolom carrier delay diabaikan oleh ringkasan/grafik. KDE menggunakan sampel 10.000 berseed seperti adaptasi pendamping.
3. **Bab 2:** proses acak tidak diharapkan identik dengan R. Standard error tidak sama dengan SD; CI ditafsirkan sebagai coverage prosedur untuk parameter tetap. Exponential diperbaiki menjadi `scale=5` untuk rate=0,2; argumen positional 0,2 di PDF adalah lokasi. Transformasi NFLX direproduksi literal tetapi semantik return harian tidak tervalidasi karena file berisi perubahan, bukan harga positif mentah. Parameter normal/t/Poisson/Weibull adalah simulasi yang diberi label, bukan observasi baru.
4. **Bab 3:** arah statistik konversi dibuat A−B pada observasi dan permutasi; ties serta koreksi Monte Carlo dijelaskan. Welch memakai `alternative` eksplisit. Mean ANOVA dihitung dari 20 observasi: grand mean 173,9 (bukan 173,75 pada prosa); residual df=16. F dan p dari `f_oneway` tidak dibagi dua. Permutasi chi-square menggunakan tiga grup saling lepas dengan margin tetap, memperbaiki tiga sampling terpisah di PDF. Exact 2×3 menjumlahkan 630 kemungkinan tabel dan mereproduksi R p≈0,482414. Power Python buku memakai TTestIndPower; NormalIndPower ditampilkan untuk membedakan pendekatan.
5. **Bab 4:** `dtype` dummy eksplisit, stepwise AIC lokal mengganti helper dmba untuk membatasi dependency (hasil delapan prediktor sesuai contoh buku). `house_sales` menyimpan label baris awal di kolom ekstra tanpa header: indeks file 24333 adalah posisi Python 20428/R 20429. Koefisien Townhouse ≈−115.122 mengikuti output, bukan salah tulis prosa >150 ribu. Prediksi vacant lot memakai koefisien presisi penuh. ZipGroup penuh-data hanya reproduksi in-sample; CV dasar menggunakan PropertyID agar tidak bocor antartransaksi. Koefisien raw polynomial berbeda dari basis orthogonal R; helper partial residual memakai matriks desain. GAM gridsearch memilih penalti pada basis 12 spline; ini bukan penetapan knot optimal universal.
6. **API:** `seaborn` memakai `data=`, `x=`, `y=`; pandas memakai agregasi kolom eksplisit, `observed=False` jika bin kosong perlu dipertahankan, `dtype=int` untuk dummy, dan pemeriksaan indeks unik terpisah. Tidak ada environment baru yang dibuat atau `.venv-1` yang dihapus.
